## 01. What happens when you add 0 to the values 
- NaN
- Infinity
- false
- true
- null
- and undefined? 

| Data type | `+0` Result |
| --------- | --------- |
| NaN       |  NaN      |
| Infinity  | Infinity  |
| false     | 0         |
| true      | 1         |
| null      | 0         |
| undefined | NaN       |

| --------- | ------------- |
| NaN       | NaN           |
| Infinity  | Infinity      |
| false     | false         |
| true      | true          |
| null      | null          |
| undefined | undefined     |
